## Cómo subirlo a GitHub

1. Descomprime este ZIP.
2. En tu repositorio de GitHub, sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. Crea una carpeta llamada exactamente `assets` en la raíz.
4. Sube dentro de `assets` las 48 imágenes incluidas en la carpeta `assets` de este ZIP.
5. No cambies los nombres de los archivos: `script.js` ya contiene las rutas `assets/nombre-de-imagen.jpg`.
6. Activa o actualiza GitHub Pages/Vercel como lo haces normalmente.
